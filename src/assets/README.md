Organize your static assets under these subfolders:

`src/assets/images/` - logo and other image files (we added `logo-light.svg` and `logo-dark.svg`).
`src/assets/icons/` - small SVG/PNG icons.
`src/assets/videos/` - loading videos or other media files.

Suggested filenames:

- `images/logo-light.svg`
- `images/logo-dark.svg`
- `videos/loading.mp4`

Add real media files into these folders when ready.
